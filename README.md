# Surface Water Quality Conditions

### Retrospective Monitoring Dashboard for Ecological Risk Assessment

This repository contains a functional, interactive dashboard designed as a work example for the **EPA Office of Pesticide Programs (OPP), Environmental Fate and Effects Division (EFED)**. It demonstrates the programmatic retrieval, cleaning, and visualization of multi-agency surface water monitoring data.

[**View the Live Dashboard Here**](https://jmhatch.github.io/EPA-OPP-Example/) *(Runs entirely client-side in the browser via Shinylive/WebAssembly)*
